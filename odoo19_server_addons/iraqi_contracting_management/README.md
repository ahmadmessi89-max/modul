# إدارة المقاولات وحسابات المشاريع الإنشائية العراقية (Odoo 19)
## Iraqi Contracting & Project Costing Management Module

موديول مخصص ومتكامل مبني وفق معايير **Odoo 19** وموجّه لشركات المقاولات العامة، مكاتب الاستشارات الهندسية، والشركات الإنشائية العاملة في جمهورية العراق. يربط النظام بين الجوانب الهندسية (جداول الكميات والتسعير، أوامر الغيار، والذرعات الشهرية) والجوانب المحاسبية والرقابية (الاستقطاعات النظامية، استرداد السلف التشغيلية، وموازنات التكاليف التحليلية ثلاثية الأبعاد).

---

## 🏛️ جدول المصطلحات الهندسية والمحاسبية المعتمدة (Iraqi Terminology Mapping)

تم تعريب وضبط كافة الواجهات والتقارير والنماذج وفق المصطلحات العراقية الرسمية بدقة متناهية:

| المصطلح الإنجليزي | المصطلح العراقي المعتمد | المعنى والاستخدام في الموديول |
| :--- | :--- | :--- |
| **Bill of Quantities (BOQ)** | **جدول الكميات والتسعير (WBS)** | جدول البنود وفقرات العقد الهندسية المسعرة |
| **Interim Payment Certificate (IPC)** | **سلفة منجزة / ذرعة شهرية دورية** | كشف قياس ومطابقة الأعمال المنجزة في الموقع دورياً |
| **Subcontractor** | **مقاول ثانوي (مقاول باطن)** | المقاول المكلف بتنفيذ حزم تخصصية |
| **Variation Order (VO)** | **أمر غيار** | أوامر التغيير الوزارية/الهندسية لتعديل الكميات أو إضافة فقرات |
| **Retention Money** | **أمانات صيانة / استقطاعات نظامية** | النسبة المحتجزة (5% أو 10%) لضمان حسن التنفيذ والصيانة |
| **Advance Payment** | **السلفة الأولية / التشغيلية** | السلفة الممنوحة لبدء العمل واستردادها بنسب من السلف المنجزة |
| **Site Material Delivery** | **إدخال مخزني موقعي** | استلام وتوريد المواد لمخزن الموقع |
| **Petty Cash** | **سلفة نقدية موقعية / ذمة المهندس** | النثريات والمصاريف الموقعية العاجلة |
| **Direct Labor / Site Wages** | **أجور يوميات عمال الموقع** | أجور المياومة والخلفات والعمالة المباشرة |

## 🏗️ البنية المعمارية للموديول (Core Architecture)

### 1. جدول الكميات والتسعير (`contracting.project.boq`)
- تتبع كامل لكل فقرة: رقم الفقرة، الوصف الهندسي، حزمة العمل (`BOQ Package`)، وحدة القياس (`UoM`).
- السعر العقدي (`Tender Price`)، الكمية الأصلية، تعديلات أوامر الغيار (+/-)، والكمية المعدلة.
- موازنة التكلفة التقديرية (`Total Estimated Budget`)، التكاليف المحجوزة بأوامر الشراء (`Committed Costs`)، التكاليف الفعلية المصروفة (`Actual Costs`)، والرصيد المتبقي المتاح للصرف.
- تتبع الذرعة التراكمية السابقة، ذرعة الفترة الحالية، والذرعة التراكمية الإجمالية ونسبة الإنجاز المئوية.

### 2. إدارة أوامر الغيار (`contracting.variation.order`)
- دورة حياة متكاملة:
  `مسودة (Draft)` ⬅️ `مقدم للمهندس المقيم (Submitted)` ⬅️ `موافق عليه من المهندس المقيم (Engineer Approved)` ⬅️ `موافق عليه من رب العمل (Client Approved)` ⬅️ `مرفوض (Rejected)`.
- دعم كافة أنواع التعديل:
  - تعديل كمية فقرة قائمة (+/-)
  - إضافة فقرة مستحدثة جديدة
  - تعديل سعر الوحدة
  - حذف أو تقليص فقرة
- تحديث تلقائي وفوري لإيرادات العقد في المشروع وموازنات بنود جدول الكميات فور المصادقة.

### 3. السلف المنجزة والذرعات الدورية (`contracting.interim.payment`)
- دعم كامل لسلف رب العمل (`Client IPC`) وذرعات المقاولين الثانويين (`Subcontractor IPC`).
- زر مخصص لجلب بنود جدول الكميات والتراكمي السابق آلياً.
- قياس ذرعة الفترة واحتساب التراكمي الإجمالي والمبالغ المستحقة.
- **صندوق الاستقطاعات والأمانات التلقائي**:
  - **استرداد السلفة التشغيلية**: احتساب نسبة الاستقطاع المعتمدة وإطفاء رصيد السلفة.
  - **أمانات الصيانة والاستقطاعات النظامية**: احتساب النسبة وتوجيه القيد آلياً لحساب الأمانات المدينة/الدائنة.
  - **استقطاعات وغرامات أخرى**: لإثبات أي فحوصات أو غرامات موقعية.
- زر توليد الفاتورة / القيد المحاسبي (`account.move`) بأسطر تفصيلية وتوزيع تحليلي.

### 4. الرقابة التكاليفية ثلاثية الأبعاد (3D Analytic Budgeting - Odoo 19)
توزيع تحليلي تلقائي (`Json format: analytic_distribution`) على 3 أبعاد:
1. **البُعد الأول**: خطة المشاريع الإنشائية (`Projects Plan`).
2. **البُعد الثاني**: خطة حزم العمل (`BOQ Packages`: ترابية وأساسات، هياكل كونكريتية، إنهاءات، كهروميكانيك MEP).
3. **البُعد الثالث**: خطة عناصر التكلفة (`Cost Elements`: مواد خامات، مقاولين ثانويين، آليات ومعدات، أجور يوميات).

### 5. الرقابة على أوامر الشراء (`purchase.order`)
- ربط أوامر الشراء بالمشروع الإنشائي وفقرة جدول الكميات وعنصر التكلفة.
- منع تجاوز المتبقي من ميزانية البند التقديرية عند محاولة تأكيد أمر الشراء مع إظهار التنبيه الرقابي العراقي المعتمد:
  > **"تنبيه رقابي: تجاوزت القيمة المتبقية من ميزانية جدول الكميات لهذا البند. يرجى مراجعة المهندس المقيم أو استخراج (أمر غيار) معتمد."**

## 🔒 الصلاحيات والأمان (Security & Roles)

1. **مهندس الموقع (`group_contracting_site_engineer`)**:
   - متابعة بنود جدول الكميات للمشاريع المكلف بها.
   - تسجيل الذرعات الموقعية وإعداد مسودات أوامر الغيار.
   - قيود وصول (`Record Rules`) تمنعه من رؤية مشاريع المهندسين الآخرين.

2. **مدير المشروع (`group_contracting_project_manager`)**:
   - اعتماد جداول الكميات، تقديم وتصديق أوامر الغيار.
   - المصادقة الفنية على الذرعات والسلف المنجزة.

3. **المدقق المالي للمشاريع (`group_contracting_financial_auditor`)**:
   - تدقيق القيود المالية للذرعات.
   - مراجعة استقطاعات الصيانة واسترداد السلف التشغيلية وتوليد الفواتير والقيود.

## 📄 تقارير QWeb PDF الاحترافية

1. **كشف ذرعة منجزة دورية (Monthly Progress Certificate - IPC)**:
   - تصميم Landscape A4 رسمي.
   - ترويسة معتمدة، جدول كميات ومبالغ (سابق، حالي، تراكمي)، مصفوفة الحساب الختامي والاستقطاعات، وتواقيع اللجان الهندسية والمالية.
2. **جدول الكميات والتسعير المعتمد (Approved BOQ Report)**:
   - تفريغ كامل لبنود المشروع ومواصفاتها الفنية وقيمتها الأصلية والمعدلة.

## 🚀 طريقة التثبيت والاستخدام السريع

1. انسخ مجلد الموديول `iraqi_contracting_management` إلى مسار الموديولات المخصصة (`addons_path`).
2. قم بتحديث قائمة التطبيقات (`Update Apps List`).
3. ابحث عن `iraqi_contracting_management` واضغط على **Install**.
4. انتقل إلى القائمة الرئيسية **"إدارة المقاولات"**:
   - افتح الإعدادات واضبط حساب أمانات الصيانة والسلفة التشغيلية.
   - أنشئ مشروعك الإنشائي وأدخل فقرات جدول الكميات.
   - ابدأ بإصدار أوامر الغيار والذرعات الدورية بكل سهولة!
