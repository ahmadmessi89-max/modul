# تطبيقات أودو كميونتي المجربة (Odoo Tested Community Apps)

حزمة تطبيقات وموديولات أودو المجربة والمتوافقة، جاهزة للاستخدام والتثبيت المباشر.

---

## 📦 محتويات المستودع (ZIP Packages & Source):

### 1. 📊 تقارير المحاسبة PDF (`accounting_pdf_reports.zip`)
- طباعة ميزان المراجعة، الأستاذ العام، دفتر اليومية، وأعمار الديون بصيغة PDF احترافية.
- متوافق مع نظام أودو المحاسبي.

### 2. 📑 تقارير OCA المالية والمحاسبية (`OCA_Accounting_Financial_Reports.zip`)
- حزمة التقارير المالية المتطورة من منظمة OCA (ميزان المراجعة التفاعلي، كشف الحسابات، ضريبة القيمة المضافة).

### 3. 📱 المظهر المتجاوب للهواتف والشاشات (`web_responsive_enterprise-19.0.2.0.0.zip`)
- تحسين واجهة المستخدم لتصبح متجاوبة بالكامل مع الأجهزة المحمولة وشاشات اللمس (Mobile Responsive Interface).

### 4. 🔄 تحويلات المدفوعات الداخلية (`zxs_internal_payment_transfer.zip`)
- إدارة وتسهيل التحويلات المالية الداخلية بين البنوك والصناديق النقدية.

---

## 🚀 طريقة الاستخدام والتثبيت (Installation):
1. قم بتحميل ملف الـ ZIP الخاص بالتطبيق المطلوب من المستودع أو استخرج مجلده من مجلد `extracted_modules/`.
2. ضع المجلد المستخرج داخل مسار الـ `addons` في سيرفر أودو الخاص بك.
3. حدّث قائمة التطبيقات في أودو (**Apps -> Update Apps List**).
4. فعّل التطبيق المطلوب (**Activate / Install**).
